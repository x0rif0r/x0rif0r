### [AppDock](https://github.com/x0rif0r/AppDock)

A macOS app for keeping your iPhone apps organized — from Apple ID purchase history to an IPA library and USB installation.

| Discover | Keep | Install |
| :--- | :--- | :--- |
| Browse purchase history and match apps from a connected iPhone | Organize IPA files locally or on a NAS | Queue downloads and install over USB |

**SwiftUI** · **macOS** · **Local / NAS** · **MIT**

[Explore the project →](https://github.com/x0rif0r/AppDock) · [Download →](https://github.com/x0rif0r/AppDock/releases) · [Contribute →](https://github.com/x0rif0r/AppDock/blob/main/CONTRIBUTING.md)
